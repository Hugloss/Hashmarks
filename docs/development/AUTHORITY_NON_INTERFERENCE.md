# Authority non-interference program

This program is additive to the repository-quality qualification plan. It does not replace or remove retained corpus, dogfood, metamorphic, mutation, provenance, ranking, economics, or convergence work.

## Normative invariants

**Authority non-interference.** Repository authority is determined by canonical repository evidence, normalized task semantics, repository generation, and the declared authority policy. Retrieval economics and presentation controls may change what is shown, but must not directly change authority, uniqueness, ambiguity, ownership, verification ownership, or another proof-bearing conclusion.

**Evidence non-erasure.** Evidence may raise a hypothesis. Only admissible repository evidence may promote it into an authoritative or actionable conclusion. Contradictory evidence may change the conclusion without deleting the observation.

Token budgets constrain evidence presentation; they never weaken truth conditions. Relative superiority is not positive authority evidence. The best visible candidate is not automatically an authority.

## Program phases

1. Freeze retrieval-bound, zero-positive-evidence, ambiguity, cross-surface, and proof/presentation identity invariants.
2. Separate retrieval candidates, authority candidates, authority evidence, authority proofs, authority decisions, and presentation projections.
3. Declare proof obligations and fail closed when proof scope is incomplete.
4. Make ambiguity sticky through compaction, pagination, CLI/MCP, and agent projections.
5. Bind proof identity to repository/task/policy/generation while presentation identity owns retrieval/display controls.
6. Add semantic metamorphic qualification for limits, pagination, order, cache, rebuild, irrelevant additions, equivalent wording, batching, compact/full, and CLI/MCP.
7. Converge orient, outline, affected, tests, task-evidence, findings, MCP, compact packets, and future external-evidence projections on one canonical authority result.
8. Make contradictory evidence, interpretation confidence, actionability, and evidence hierarchy first-class for finding false-positive reduction.
9. Bind authority to repository generation and counterfactual ownership mutations.
10. Expose bounded-output completeness metadata and keep external evidence correlation separate from repository ownership proof.

## Hard qualification vetoes

Qualification is non-compensatory. Any false authority, false safe edit, false unique conclusion, or unjustified actionable finding is a hard failure. Ranking quality, evidence retention, latency, token economy, or aggregate diagnostics cannot compensate.

## Product boundary

Hashmarks remains a repository/evidence intelligence layer. It is not an editing agent, execution motor, retry/recovery engine, workflow orchestrator, persistent failed-edit memory, log-ingestion service, observability backend, or agent permission system.

## Definition of done

Authority is invariant to presentation-only controls; bounded search may abstain instead of guessing; synthetic candidates require admissible positive evidence; ambiguity survives truncation; proof and presentation identities are separate; legitimate authority transitions name their new admissible evidence; surfaces converge; generation mutation invalidates or revalidates proof; false-positive explanations retain observations and counter-evidence; external evidence never automatically confers edit ownership; and all hard authority counters remain zero.


## Batched convergence implementation

The next qualification layer turns these invariants into structured evidence rather than relying only on producer-supplied booleans.

- Structured authority observations derive false-authority, external-evidence leakage, stale-evidence promotion, mixed-generation authority, and projection-promotion vetoes.
- Structured finding observations make actionability depend on admissible, non-contradicted evidence. Counter-evidence is retained; it is not erased to preserve a finding.
- Executed metamorphic observations bind baseline and candidate authority-proof identities. Presentation-only families expect invariant authority; generation mutation may explicitly require an authority change.
- Any legitimate authority transition that changes proof identity must name the new admissible evidence that caused the transition.
- Proof-profile minimums are visible per evaluation profile. They are diagnostic until empirical corpus coverage justifies making a minimum qualification-blocking; absence never silently counts as proof.
- Wilson 95% intervals describe uncertainty for bounded quality rates. They are descriptive and cannot compensate for a hard-zero authority failure.
- Bounded presentation contracts report total/returned candidates and complete/truncated state while retaining the same authority-proof identity. Presentation identity owns limit/per-role/compact controls.
- External evidence can correlate with repository evidence but external-evidence-only observations can never establish repository ownership authority.

### Metamorphic families

The qualification vocabulary now includes retrieval limit, pagination, candidate order, cache/rebuild, irrelevant-file addition, equivalent wording, batching, compact/full, CLI/MCP, and generation mutation. Merely tagging a case with a family is not execution evidence: executed cases must provide both proof identities and the expected relation.

### Remaining retained program

This batch does not close the program. Real repository executions must still populate the retained L2 and fresh L3 corpora, especially Oh-Goon 993; cross-surface CLI/MCP/task-evidence/findings convergence must be exercised against actual bytes; generation and counterfactual ownership mutations need retained fixtures; selected mutation-testing challenges must be run; external-evidence correlation needs end-to-end qualification; ranking and evidence-retention quality need real corpus measurements; economics need comparable environment fingerprints; and final convergence must remain green with every hard-zero authority counter at zero.


## Retained corpus and mutation batch

The qualification program now owns an immutable corpus-manifest contract with explicit L1 synthetic, L2 retained real-world, and L3 fresh-dogfood layers. Real-world cases require provenance references; qualification membership has a separate identity from diagnostic membership; and promotion from shadow/canary to qualification requires reviewer and evidence identities. Historical evidence cannot be silently re-promoted.

The first L2 manifest retains the Oh-Goon 1267.0.993 publish-strict-attempt ownership and verification-locality defects as qualification cases. The physical-attempt reincarnation task remains shadow evidence until it is freshly executed and reviewed. This deliberately distinguishes retained proof from fresh L3 dogfood instead of pretending historical evidence is current execution.

A selected mutation harness now executes presentation-invariance challenges for retrieval limit, pagination, candidate ordering, compact/full projection, and irrelevant additions, plus an expected-change generation mutation. The harness reports proof-identity drift rather than granting product authority. A cross-surface convergence contract likewise requires orient/outline/affected/tests/task-evidence/findings/MCP/compact observations to converge on one authority-proof identity when those surfaces are claimed as a proof set.

This still does not close the retained plan: fresh L3 Oh-Goon execution, actual surface-output adapters, counterfactual repository fixtures, external-evidence end-to-end correlation, richer related-evidence ranking, comparable economics, and final convergence remain required.
