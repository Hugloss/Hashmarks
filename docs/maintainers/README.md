# Hashmarks maintainer documentation

This directory contains **current implementation-navigation guidance** for developers changing Hashmarks internals.

It is different from:

- `docs/reference/` — normative product/architecture contracts;
- `docs/integration/` — current interoperability contracts;
- `docs/development/` — historical development evidence, handoffs, audits, and reviews.

Maintainer documentation explains where current code responsibilities live and how to trace common flows. It does not override public contracts or tests.

Start with [`CODEMAP.md`](CODEMAP.md) when changing repository-intelligence internals.
