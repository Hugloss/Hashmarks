# Hashmarks maintainer documentation

This directory contains **current implementation and maintenance guidance** for developers changing Hashmarks internals.

It is different from:

- `docs/reference/` — normative product/architecture contracts;
- `docs/integration/` — current interoperability contracts;
- `docs/qualification/` — current qualification semantics.

Maintainer documentation explains where current code responsibilities live and how repository maintenance is performed. Superseded plans and handoffs belong to Git/PR history.

Start with:

- [`CODEMAP.md`](CODEMAP.md) for repository-intelligence ownership and request flows.
- [`RESPONSIBILITY_REFACTORING.md`](RESPONSIBILITY_REFACTORING.md) before structural/complexity cleanup.
- [`RELEASING.md`](RELEASING.md) for the current release process.
